# Проверка приложения в Chrome (Flutter Web)

Проект полностью совместим с Web: тот же код, что и на Android/iOS.
Хранилище `shared_preferences` на Web автоматически работает через
localStorage, поэтому прогресс сохраняется между перезагрузками.

## Запуск

```bash
cd time_to_grow

# 1. Один раз: сгенерировать платформенные папки (web/, android/, ios/)
flutter create .

# 2. Загрузить зависимости
flutter pub get

# 3. Запустить в Chrome
flutter run -d chrome
```

`flutter run -d chrome` открывает приложение с горячей перезагрузкой
(нажмите `r` в терминале после правок кода).

## Чек-лист проверки функций

| Функция | Как проверить |
|---|---|
| Выбор питомца | При первом запуске (или Профиль → «Сбросить прогресс») открывается большой экран выбора: 4 карточки с живой анимацией. Выберите Котика → «Встречаем «Котика»!» |
| Рост по экранному времени | Нажмите «Отложить телефон» → **скройте вкладку** (Alt+Tab, другое окно) → вернитесь через минуту: таймер насчитал время, статус «🌱 рост идёт». Пока вкладка активна — счёт на паузе |
| Машина времени ×60 | Профиль → включите тумблер: 1 секунда = 1 минута, счёт идёт всегда. За 30 секунд питомец-яйцо станет малышом (порог 5 мин), за 2 минуты — взрослым |
| Эволюция | 0 → 5 → 15 → 30 минут: яйцо → малыш → подросток → взрослый; после 30 мин на кнопке появится «Выбрать нового питомца» |
| ИИ-дневник | Вкладка «Дневник»: без ключа — мгновенный офлайн-анализ настроения; с ключом (Профиль → «ИИ-дневник») — живой ответ модели |
| Челлендж | Вкладка «Челлендж»: боты + ваши реальные минуты за неделю |
| Обновления | Профиль → «Симулировать обновление» → баннер сверху; либо «URL проверки обновлений» → свой `version.json` |

## Особенности Web

- **LLM-запросы**: браузер блокирует прямые запросы к OpenAI/OpenRouter
  (CORS). Для Web-релиза используйте прокси-бэкенд (см. README, раздел
  «Безопасность ключа») или провайдера с разрешённым CORS (например,
  Groq для тестов).
- **Экранное время**: точный Android-канал (UsageStats) на Web
  недоступен — считается время вне вкладки. Подробности:
  [SCREEN_TIME.md](SCREEN_TIME.md).
- **Релиз-сборка для хостинга**: `flutter build web --release`,
  результат в `build/web` (можно выложить на GitHub Pages).
