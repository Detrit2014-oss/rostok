# Погода на сцене питомца (v1.7.0)

Сцена главного экрана «Ростка» реагирует на реальную погоду за окном:
солнце, облака, туман, дождь, снег и даже гроза с молнией.

## Как это работает

1. Приложение определяет местоположение (`geolocator`, точность low).
2. Координаты уходят в [Open-Meteo](https://open-meteo.com/) — бесплатный
   сервис погоды **без API-ключа**:
   `https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=weather_code`
3. Код погоды WMO переводится в одно из 7 состояний сцены:

| WMO          | Состояние           | Сцена                                  |
|--------------|---------------------|----------------------------------------|
| 0            | Ясно                | Солнце, обычные облака                 |
| 1–2          | Переменная облачность | Доп. облака                          |
| 3            | Облачно             | Серое небо, больше облаков             |
| 45, 48       | Туман               | Полупрозрачные полосы тумана           |
| 51–67, 80–82 | Дождь               | Падающие капли, приглушённое небо      |
| 71–77, 85–86 | Снег                | Снежинки, светлое небо                 |
| 95+          | Гроза               | Тёмное небо, вспышки молний            |

4. При ошибке (нет разрешения, нет сети) показывается **детерминированная
   «погода по дате»** — та же логика, что и в веб-демо.

## Режимы

- **Авто (GPS)** — погода по местоположению (по умолчанию).
- **По дате** — стабильная погода по календарному дню (без запросов GPS).
  Переключение: Профиль → «Погода в мире».

## Веб-демо

В демо используется тот же Open-Meteo, но геолокация берётся из браузера
(`navigator.geolocation`). Для сетки из 30 карточек выбора используется
режим «По дате», чтобы не отправлять 30 запросов геолокации.

## Приватность

Координаты используются только для запроса погоды, никуда не сохраняются
и не передаются третьим лицам, кроме Open-Meteo (широта/долгота с точностью
до 0.001°).
