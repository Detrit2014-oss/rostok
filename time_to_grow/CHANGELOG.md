# История версий — «Время Расти»

Формат: семантическое версионирование MAJOR.MINOR.PATCH (в pubspec: version: X.Y.Z+build).
Каждому релизу соответствуют: запись здесь, обновление `lib/core/app_version.dart`
и нового `update/version.json` на хостинге (см. docs/UPDATE_FLOW.md).

## 1.1.0 — 2026-09-22
### Добавлено
- **Экран выбора питомца**: при первом запуске открывается большой выбор —
  4 вида на крупных живых карточках (лисёнок, котик, совёнок, дракончик),
  у каждого характер и анимированное превью малыша. После взросления питомца
  выбор появляется снова («Выбрать нового питомца»), после сброса прогресса — тоже.
- **Рост привязан к экранному времени телефона**: засчитываются только минуты,
  когда пользователя не было в приложении и экран был погашен. Пока приложение
  открыто — счёт на паузе (статус «⏸ экран включён» / «🌱 рост идёт»).
- **Точный учёт на Android** (опционально): ScreenTimeService + готовый
  MainActivity.kt (docs/SCREEN_TIME.md) — из системных событий экрана
  вычитается время с включённым экраном; статус и кнопка выдачи доступа
  в Профиле («Экранное время»).
- **Прозрачность счёта**: в карточке сессии видно «Экран горел: X мин — не в счёт»,
  а при завершении без отдыха — подсказка «Пока 0 мин — телефон не отдыхал».
- docs/WEB_TESTING.md — пошаговая проверка всех функций в Chrome.

### Изменено
- Первый питомец больше не создаётся автоматически — вид выбирает пользователь.
- Машина времени ×60 теперь явно «обходит» экранный учёт (считает всё время) —
  для быстрых тестов в Chrome.

## 1.0.0 — 2026-09-22
### Добавлено
- Питомец — сердце приложения: яйцо → малыш → подросток → взрослый.
  Растёт от минут, проведённых вне телефона; коллекция питомцев 4 видов
  (лисёнок, котик, совёнок, дракончик), переименование, поздравление при взрослении.
- Анимированная сцена без единого ассета (CustomPaint): небо, солнце, облака,
  лужайка, моргание, лёгкий бонс, спящий режим с «zzz» во время сессии.
- Сессии цифрового детокса: таймер по реальному времени; приложение свёрнуто —
  минуты продолжают накапливаться; восстановление сессии после перезапуска.
- ИИ-дневник настроения: мгновенный офлайн-анализ + подключение реального LLM
  (любой OpenAI-совместимый API: OpenAI, OpenRouter, Groq, свой прокси),
  анимация «печатающегося» ответа ИИ-садовника, лента настроения за 7 дней.
- Челленджи с друзьями (демо-режим): недельная «Детокс-неделя», лидерборд,
  друзья-боты, свой челлендж с целью в часах; интерфейс бэкенда готов под Firebase.
- Система обновлений (гибрид): проверка version.json по URL при запуске и раз в 6 часов,
  баннер «Доступно обновление» на всех экранах, симуляция для теста, ручная проверка,
  URL настраивается в Профиле; зарезервирован источник Firebase Remote Config (v2).
- Машина времени ×60: 1 секунда = 1 минута — быстрая проверка роста в Chrome.
- Профиль: статистика (часы вне телефона, серия дней, взрослые питомцы, записи).
