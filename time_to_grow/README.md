# 🐣 Время Расти (Time to Grow) — v1.1.0

Кроссплатформенное Flutter-приложение о цифровой гигиене и ментальном здоровье.
Идея: вы откладываете телефон — растёт виртуальный питомец. Тестируется в
Chrome, выпускается на Android и iOS — один код на все платформы.

## Ключевые функции v1.2.0

- 🐾 **Большой выбор питомца** при первом запуске (и после взросления):
  10 видов на больших живых карточках — лисёнок, котик, совёнок, дракончик,
  уточка, зайчик, пингвинёнок, ёжик, панда и медвежонок (+ кубик «Случайный»).
- 📵 **Рост привязан к экранному времени**: засчитываются только минуты
  с погашенным экраном. На Android — точно, по системным данным (UsageStats,
  docs/SCREEN_TIME.md); на iOS/Web — время вне приложения.
- 🥚 **Питомец растёт** от минут вне телефона: Яйцо → Малыш → Подросток →
  Взрослый; имена, коллекция, поздравления.
- 🎨 **Анимированная сцена без единого ассета** (CustomPaint): небо, солнце,
  облака, лужайка, моргание, бонс, спящий режим «zzz» во время сессии.
- ⏱ **Сессии детокса**: счёт переживает перезапуск приложения; прозрачность
  — «Экран горел: X мин — не в счёт»; серия дней подряд.
- 🤖 **ИИ-дневник настроения**: мгновенный офлайн-анализ + реальный LLM
  (OpenAI-совместимый API), анимация печатания, лента настроения за 7 дней.
- 🏆 **Челленджи с друзьями** (демо-режим): «Детокс-неделя», лидерборд, боты;
  интерфейс бэкенда готов под Firebase (docs/FIREBASE.md).
- ⬆️ **Система обновлений**: баннер «Доступно обновление» на всех экранах,
  version.json по URL, симуляция для теста (docs/UPDATE_FLOW.md).
- ⚡ **Машина времени ×60**: 1 секунда = 1 минута, считает всё время —
  быстрая проверка роста в Chrome без ожидания.

## Быстрый старт

```bash
cd time_to_grow
flutter create . --platforms=web,android,ios --org com.yourname
flutter pub get
flutter run -d chrome        # тест в браузере
flutter run                  # или на подключённом телефоне
```

`flutter create .` создаст недостающие папки платформ (android/, ios/, web/),
не трогая существующий код. Смок-тест: `flutter test`.

Подробный чек-лист проверки в Chrome — [docs/WEB_TESTING.md](docs/WEB_TESTING.md);
точный учёт экранного времени на Android — [docs/SCREEN_TIME.md](docs/SCREEN_TIME.md).

## Имя приложения на платформах

- Android: `android/app/src/main/AndroidManifest.xml` → `android:label="Время Расти"`
- iOS: `ios/Runner/Info.plist` → `CFBundleDisplayName` = Время Расти
- Web: `web/index.html` → `<title>Время Расти</title>`, `web/manifest.json` → `name`/`short_name`

## ИИ-дневник (LLM)

По умолчанию работает офлайн-анализ (словари + эмпатичные подборки).
Чтобы включить настоящую модель: Профиль → «ИИ-дневник (LLM)» → Base URL,
модель, API-ключ. Подходит любой OpenAI-совместимый API (OpenAI, OpenRouter,
Groq, свой прокси). Ключ хранится только на устройстве.

**Безопасность к релизу**: ключ не должен жить в клиенте — поднимите
тонкий прокси (Cloud Functions / любой бэкенд), который хранит ключ и
проксирует `chat/completions`; в приложении тогда Base URL = ваш прокси.

## Обновления (кратко)

1. Меняете код → поднимаете версию (`pubspec.yaml`, `app_version.dart`, `CHANGELOG.md`).
2. Публикуете сборки в сторы.
3. Правите `update/version.json` на хостинге (GitHub Pages).
4. Все устройства видят баннер «Доступно обновление» на всех экранах.

Полная инструкция: `docs/UPDATE_FLOW.md`. Проверка без сервера:
Профиль → «Симулировать обновление».

## Структура проекта

```
lib/
├── main.dart                  — композиция сервисов и провайдеров
├── app.dart                   — MaterialApp и тема
├── core/                      — версия, тема (игровая палитра), утилиты
├── models/                    — Pet, DiaryEntry, Challenge, AppUpdateInfo
├── data/pet_catalog.dart      — виды питомцев (описания, эмодзи, падежи)
├── services/                  — вся бизнес-логика (ChangeNotifier)
│   ├── pet_service.dart       — питомцы и статистика (+ createPet по выбору)
│   ├── focus_session_service.dart — сессии по экранному времени (away/counted)
│   ├── screen_time_service.dart   — мост к Android UsageStats (MethodChannel)
│   ├── mood_ai.dart           — офлайн-анализ дневника
│   ├── llm_service.dart       — реальный LLM (OpenAI-совместимый)
│   ├── diary_service.dart     — дневник (офлайн + LLM)
│   ├── challenge_service.dart — недельный челлендж
│   ├── challenge_backend.dart — интерфейс бэкенда (демо ↔ Firestore)
│   ├── update_service.dart    — проверка обновлений
│   └── update_source.dart     — источники: JSON ↔ Remote Config (заготовка)
├── screens/                   — выбор питомца + 4 вкладки: Питомец, Дневник, Челлендж, Профиль
└── widgets/                   — сцена питомца, карточки, пухлые кнопки, баннер
```
