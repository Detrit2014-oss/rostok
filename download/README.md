# Загружаемые файлы «Ростка»

## rostok_v1.8.0.zip
Исходники Flutter-приложения «Росток» v1.8.0 (build 9): 30 персонажей
(24 зверя + 6 растений), XP-экономика с монетками, магазин с рамками и
заморозкой серии 🧊, мини-игра «Покорми питомца» (питомец ловит еду ртом),
ежедневные задания, сон питомца, погода на сцене (Open-Meteo), открытки,
23 достижения. Сборка: `flutter build apk --release` (инструкции в README).

Веб-демо 1:1: вкладка «Профиль» → ссылка на этот архив; version.json
демо симулирует следующую версию (1.9.0) для показа баннера обновлений.
