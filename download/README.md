# Загружаемые файлы «Ростка»

## rostok_v2.1.0.zip
Исходники Flutter-приложения «Росток» v2.1.0 (build 12) — «Настоящие звери»,
полностью новая отрисовка: каждый из 30 видов — реалистичная
иллюстрация-спрайт в едином энциклопедическом стиле (натуральные пропорции,
окрас, шерсть/перья), 24 вида имеют настоящие ПОЗЫ СНА (лиса свернулась
клубком, совёнок спрятал клюв, пингвинёнок спит стоя). Кит и водные жители —
полноценные иллюстрации в пруду (больше не «прозрачные»), у кита фонтанчик.
Растения растут на грядке с деревянным бортиком. Повадки сохранены: зверь
гуляет по полосам глубины, принюхивается, щиплет траву, сидит, птицы клюют,
зайчик прыгает. Гардероб: вместо окрасов — новые аксессуары (бандана,
колокольчик, цветочек), купленные окрасы возвращены монетками.
Плюс всё из прошлых версий: 30 персонажей (24 зверя + 6 растений),
возрастные подарки, рисованые монетки, XP-экономика, магазин с рамками
и заморозкой серии, мини-игра «Покорми питомца» (еда летит в якорь морды),
задания, сон, погода (Open-Meteo), открытки, 23 достижения.
Спрайты лежат в `assets/sprites/` (54 WebP). Сборка: `flutter build apk --release`.

Веб-демо 1:1: те же спрайты в `public/sprites/`, вкладка «Профиль» → ссылка
на этот архив; version.json демо симулирует следующую версию для баннера.
